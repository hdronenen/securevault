# 🔐 SecureVault

SecureVault is a security-focused full-stack web application built with Java, Spring Boot, React, and PostgreSQL.

The goal of this project is to build a secure platform where users can create accounts, authenticate, and store private notes while applying real-world software engineering and cybersecurity practices.

## 🔒 Security Goals

SecureVault will focus on:

- Password hashing
- Authentication and authorization
- Secure handling of credentials
- Input validation
- Protection against common web vulnerabilities
- Audit logging
- Principle of least privilege
